# Understanding Safety Challenges for Women in Indian Cities Through Data

## 1. Project Overview

Women's safety is an important social concern, and data analysis can help us understand patterns in officially reported cases. This project explores city-level reported case data for Indian metropolitan cities in 2023 using Python.

The project focuses on examining reported case counts and understanding how cases are distributed between two categories in the dataset:

- Cases under Section 156(3) of the Code of Criminal Procedure (Cr.P.C.)
- Cases reported at police stations

The objective is to demonstrate a complete beginner-level data analysis workflow, including data cleaning, exploratory data analysis, ranking, percentage calculations, and data visualisation.

**Important:** Reported case counts are not a direct measure of women's safety or the actual prevalence of crime. The findings describe the dataset and should be interpreted within its limitations.

## 2. Project Objectives

- Load and inspect a real-world Excel dataset.
- Clean missing and unnecessary rows.
- Convert numerical columns into appropriate data types.
- Identify cities with the highest absolute reported case counts.
- Calculate the percentage distribution of cases across reporting categories.
- Visualise city-level counts using bar charts.
- Communicate findings responsibly and identify limitations in the data.
